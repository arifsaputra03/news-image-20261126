## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies the committed `entry.png` to `entry.png` in the output directory — `/output` when `MAKEFUN_OUTPUT_DIR` is not set. Every run produces exactly the same bytes.
